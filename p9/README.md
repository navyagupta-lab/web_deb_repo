# P9: Responsive navbar and card grid using Flexbox

The goal is to make a row of links and cards that can wrap when there is not enough room.

## What I used
- `display: flex` for the navigation and card list
- `gap` to keep a steady amount of space between items
- `flex-wrap: wrap` so items can move onto another line
- A media query to adjust the layout on narrow screens

Try changing the browser width to see the cards wrap.
