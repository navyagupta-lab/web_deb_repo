# P13: Choosing between Flexbox and Grid for a shared layout

Flexbox and Grid can both arrange elements, but they solve slightly different layout problems.

## My choice for this page
- I use Flexbox for the small navigation row because it mainly runs in one direction.
- I use Grid for the project cards because I want to control rows and columns together.

Neither tool is automatically better. I choose based on the shape of the layout and test it at different screen sizes.
