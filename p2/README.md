# P2: Portfolio repo with an initial commit

This exercise is about starting a small portfolio folder and saving its first version with Git.

## Steps
1. Make `index.html` and `style.css`.
2. Run `git init` in the project folder.
3. Check the files with `git status`.
4. Stage them using `git add .`.
5. Save the first snapshot with `git commit -m "Add portfolio starter"`.
6. Connect the GitHub remote and push `main`.

The page in this folder is a simple starter portfolio. CSS is external.
