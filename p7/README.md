# P7: Design tokens and typography system in CSS

Instead of repeating the same colours and spacing values, I keep the main design choices together as CSS custom properties.

## What I tried
- Put reusable values inside `:root`.
- Use the variables for headings, body text and spacing.
- Keep the font stack simple and set a comfortable line height.
- Change one token and see how it affects the page.

The values are in the external `style.css` file.
