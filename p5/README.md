# P5: Semantic bio page

This page is a short biography using HTML elements for their meaning, not just their default appearance.

## Elements used
- `header` for the page introduction
- `main` for the main content
- `section` for grouped information
- `figure` and `figcaption` for an image and its caption
- `footer` for the closing line

I would replace the sample image text with my own image and write useful alt text that describes it.
