# P8: Sticky navbar and card overlay using CSS positioning

This one is about two different positioning jobs: keeping navigation visible while scrolling and putting a label over a card image.

## Main ideas
- `position: sticky` keeps the navigation near the top while scrolling.
- The card uses `position: relative` as the reference point.
- The small label uses `position: absolute` so it sits over the card.

Try scrolling the page and resizing the browser to check the result.
