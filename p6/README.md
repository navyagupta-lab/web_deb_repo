# P6: Full portfolio page structure in semantic HTML

This exercise builds the skeleton of a portfolio page. The sections are kept in a logical order so the page is easy to read and navigate.

## Page structure
- `header` contains the name and navigation.
- `nav` holds links to page sections.
- `main` contains the actual portfolio content.
- `article` is used for each project card.
- `address` contains contact details.
- `footer` closes the page.

The sample contact details are placeholders; replace them with real details before publishing.
