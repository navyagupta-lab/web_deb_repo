# P12: Portfolio projects grid with advanced CSS Grid

This page uses Grid to arrange project cards. The featured card takes up more space, while the other cards fill the remaining grid cells.

## CSS ideas
- `repeat()` keeps the column definition shorter.
- `minmax()` lets a column shrink without becoming too narrow.
- `grid-column` lets the featured card span more than one column.
- The media query stacks the cards on smaller screens.
