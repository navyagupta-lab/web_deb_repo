A layout study · P11

FEATURE

Small projects make a big difference when learning to code

Working through one layout at a time makes it easier to understand what each CSS rule is doing. The trick is to practise, check the result and make small changes.

DESIGN

Giving type some room

Good line spacing and a sensible measure can make a page much easier to read.

TOOLS

Keep the workflow simple

Save often, write useful commit messages and keep project files organised.

LEARNING

Try it at another size

A layout that looks fine on a laptop may need a different arrangement on a phone.
