# P11: Newspaper-style three-column layout with CSS Grid

A newspaper layout is a good place to try CSS Grid because the content needs rows and columns.

## Layout notes
- The page uses a three-column grid on a wide screen.
- `gap` adds space between the stories.
- The main story spans two columns.
- A media query changes the layout to one column on a small screen.

Try changing the grid columns and watch how the story blocks move.
