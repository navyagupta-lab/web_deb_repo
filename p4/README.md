# P4: GitHub README and version tags

A README should tell someone what the project is and how to use it. A tag gives a name to a particular version.

## What to include
- A short description
- The main files and folders
- Steps to open or run the project
- Any useful notes

## Tagging a version
After committing the finished work, run `git tag v1.0.0` and then `git push origin v1.0.0`. The tag makes it easier to find that version later.
