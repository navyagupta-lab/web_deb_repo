# P1: Project folder and terminal navigation

The aim is to get comfortable moving around folders from the terminal.

## Try it
1. Run `pwd` to see your current location.
2. Use `mkdir web-development` to make a folder.
3. Move into it with `cd web-development`.
4. Use `mkdir module-1` and `cd module-1`.
5. Run `touch notes.txt` and check the folder with `ls`.

## Commands
`pwd`, `ls`, `cd`, `mkdir`, `touch`.

Open `index.html` for a small reminder page. The CSS is in `style.css`.
