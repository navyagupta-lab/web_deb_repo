# P10: Portfolio header and footer with advanced Flexbox

This exercise focuses on the top and bottom parts of a portfolio page. Flexbox helps keep the items aligned without fixed widths.

## Things to test
- Use `justify-content` to spread items across the row.
- Use `align-items` to line them up vertically.
- Allow `flex-wrap` so the header does not overflow on a small screen.
- Check the footer links at phone width too.
